## アプリへの反映

| 条件 | 実装 |
|---|---|
| 制作者・出典の表示 | 情報タブ、THIRD_PARTY_NOTICES.md、データのマニフェスト |
| ライセンスへのリンク・写し | 情報タブ、同梱ライセンス全文、リポジトリ |
| 変更の明示 | 軽量化、座標変換、抽出表示、Traced限定、圧縮形式を明記 |
| 推奨・公認と誤認させない | 独立アプリであることを表示。機関ロゴを使用しない |
| 元データに追加制限をかけない | 無料取得できる派生データと変換手順を公開。独自DRMなし |
| 原資料の範囲を保つ | 説明文・論文図版・ソフトウェアの権利をデータの権利と混同しない |

有料アプリとして価格を設定すること自体は、このCCライセンスに反しません。
CC BYには、アプリの独自コードをオープンソースにする義務もありません。
独自コード・独自日本語解説は権利留保とし、MaleCNS由来データのCC BYの権利を
優先する例外をLICENSEに設けています。

Google Playによる審査・ストア表示・価格・決済・アカウント資格は別の事項です。
ライセンスの判断はストア審査通過の保証ではありません。
