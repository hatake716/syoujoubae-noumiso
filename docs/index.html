DROSOPHILA / BRAIN ATLAS

小さな脳を、旅する。

MaleCNS v1.0の実測データで、ショウジョウバエの脳を立体的に探索するAndroidアプリです。3Dと解説の広さを調整でき、元の約771万三角形を保持した90個の領域モデルと50種類の日本語解説から、神経の形態と接続へ進めます。

165,122個の追跡済み細胞を検索し、それらの間の25,563,197本の有向接続を端末内で参照できます。全脳の神経概観は523個の実測細胞の全ての枝を静止時に表示します。個別形態の一部は初回表示時に公式配布元から取得します。
